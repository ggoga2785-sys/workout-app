# Железо — приложение для тренировок

Веб-приложение (PWA) для ведения тренировок: бодибилдинг (набор массы, рекомпозиция, сушка), фитнес и пауэрлифтинг (троеборье или одно движение, межсезонье или подводка к дате соревнований по 1ПМ). Работает в браузере телефона, ставится на главный экран, работает офлайн. Позже упаковывается в APK/iOS через Capacitor.

## Запуск

```bash
npm install
npm run dev      # разработка, http://localhost:5173
npm run build    # сборка в dist/
npm run preview  # просмотр сборки
```

## Стек

React 18 + TypeScript + Vite, `react-router-dom` (HashRouter, чтобы работало внутри APK), `zustand` с сохранением в localStorage, `vite-plugin-pwa`.

## Структура

- `src/types.ts` — модель данных: упражнения, настройки программы, программа (недели → дни → упражнения → подходы с % от 1ПМ/RPE), дневник.
- `src/data/exercises.ts` — база упражнений (120 шт.: штанга, гантели, хаммер, блоки, тренажёры, свой вес, кардио).
- `src/lib/generator.ts` — генератор программ. **Сейчас черновые шаблоны**, методики (Антимакроберт, Шейко, Верхошанский и др.) будут подставлены сюда.
- `src/screens/` — экраны: главная, программы, мастер новой программы, тренировка с записью подходов и таймером отдыха, база упражнений, профиль (1ПМ, резервная копия).
